# Jara Slice — site vitrine

Site statique, aucun build nécessaire.

## Déploiement Vercel
1. Pousser ce dossier sur GitHub (branche `main`).
2. Vercel → Add New Project → importer le repo.
3. Framework Preset: **Other** · Build Command: vide · Output Directory: racine du repo.
4. Deploy.

## Fichiers
- `index.html` — la page complète
- `support.js` — runtime de rendu (doit rester à côté de index.html)
- `uploads/` — photos produits et photos d'usage
